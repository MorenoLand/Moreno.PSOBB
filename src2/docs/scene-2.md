# Scene 2

`PsoBB.Scenes.Scene2` contains the only confirmed scene-2 member: `SelectSharedScreenState`, which
saves the current shared interface state, selects that state's ninth screen and starts fade one.
The rest of the scene, including the screen object that draws the Login / Start Game / Exit Game /
Patch Download / Register UserID menu, is not ported. No screen, layout, label or asset assignment
is claimed until that code exists.
